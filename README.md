# Rindi Indah Lestari · Portfolio

Hi! This is the code for my personal portfolio website.

I'm a Data Scientist, researcher and content creator from Banyumas, Indonesia. This site is where I put my projects, papers, certificates and contact info in one place.

The page has an ocean theme. It starts with a short underwater intro, and as you scroll down it feels like diving from the sky into the sea and ending up on the beach. You can even click the water to feed the fish 🐟

## Built with

- [Astro](https://astro.build) for the site
- [GSAP](https://gsap.com) for the animations
- [Lenis](https://lenis.darkroom.engineering) for smooth scrolling
- Plain CSS, no framework

## Run it on your computer

You need Node.js 18.20.8 or newer.

```bash
npm install
npm run dev
```

Then open http://localhost:4321 in your browser.

Other commands:

| Command | What it does |
|---|---|
| `npm run build` | Builds the site into `dist/` |
| `npm run preview` | Opens the built site |
| `npm run check` | Lists any content I still need to fill in |

Tip: add `?nosplash` to the address to skip the intro while you work.

## Where things are

Most of the content lives in simple files, so I can update it without touching the layout.

| What | File |
|---|---|
| My name, intro, skills and contact links | `src/data/profile.json` |
| Papers | `src/data/publications.json` |
| Certificates | `src/data/certificates.json` |
| Projects (one file each) | `src/content/projects/` |
| Project photos and videos | `public/images/projects/` |
| Colors and fonts | `src/styles/tokens.css` |
| Each section of the page | `src/components/` |
